# PERSONAL TASK MANAGER


## 📌 Mô tả

Personal Task Manager là một hệ thống giúp người dùng quản lý công việc cá nhân một cách hiệu quả. Người dùng có thể:

Tạo, cập nhật, xóa và xem danh sách công việc cần làm.

Đánh dấu công việc hoàn thành.

Sắp xếp công việc theo độ ưu tiên.

Thiết lập nhắc nhở công việc.

## 📌 Công nghệ sử dụng

Spring Boot: Xây dựng REST API.

Spring Security + JWT: Xác thực và phân quyền người dùng.

MySQL: Lưu trữ dữ liệu công việc.

Redis: Lưu cache công việc gần đây để cải thiện hiệu suất.

## 📌 Điểm nổi bật

Hỗ trợ đầy đủ các chức năng CRUD (tạo, đọc, cập nhật, xóa công việc).

Mỗi người dùng có danh sách công việc riêng, đảm bảo bảo mật dữ liệu cá nhân.

Hỗ trợ đăng ký và đăng nhập với xác thực JWT.

Có thể mở rộng với tính năng gửi email nhắc nhở công việc.

Hỗ trợ sắp xếp công việc theo mức độ ưu tiên.
